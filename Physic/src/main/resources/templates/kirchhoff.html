📖 Теория законов Кирхгофа

Первый закон Кирхгофа (закон токов)

Алгебраическая сумма токов в узле равна нулю: ΣI = 0.

Токи, втекающие в узел, принимаются положительными, вытекающие — отрицательными. Следствие: сколько тока входит — столько и выходит.

Второй закон Кирхгофа (закон напряжений)

В замкнутом контуре: ΣE = ΣI·R.

Правило знаков для ЭДС: берётся «+», если при обходе контура проходим через источник от «−» к «+» (стрелка ЭДС совпадает с обходом).

Правило знаков для падений: берётся «+», если ток через резистор совпадает с направлением обхода.

Расчёт погрешностей

Используется метод предельных абсолютных погрешностей:

I закон: ΔI_вых = ΔI₁ + ΔI₂ + ΔI₃ = 3·ΔI_прибора

II закон: ΔI_R3 вычисляется через частные производные функции I_R3(E₁, E₂, R₁, R₂, R₃, I_R1, I_R2) по каждому аргументу.

Относительная погрешность: δ = (Δ / |значение|) × 100%.

Составление системы уравнений

Для цепи с n узлами и m ветвями составляют (n−1) уравнений по I закону и m−(n−1) уравнений по II закону.
